# 🏦 Bank Transfer Simulation with Automated QA

## Automated Testing Project in a Simulated Banking Environment
This repository contains a small Flask application that simulates a banking interface, along with automated tests using ```pytest```. The tests follow the Page Object Model pattern and generate HTML reports for documentation.

## 🚀 Getting Started

1. Make sure you have Python 3.9+ and Chrome installed, with ```chromedriver``` added to your system ```PATH```.

2. Install the required dependencies:
   
   ```bash
   pip install flask selenium pytest pytest-html
   ```
   
3. Start the Flask server stub (it must be running before launching the tests:

   ```bash
   cd app
   python app.py
   ```

4. In a separate terminal, run the tests:

   ```bash
   cd ..
   pytest tests/test_transferencias.py --html=reports/test_report.html
   ```

## ✅ Covered Functionality

- Sending simulated bank transfer instructions.

- Validating responses generated by a mock AI model.

- Generating detailed test reports using ```pytest-html```.

## 🧠 Technologies Used

- **Flask** – To build the stub banking app.

- **Selenium** – To automate interaction with the web interface.

- **Pytest** – The main testing framework.

- **Pytest-HTML** – For generating human-readable test report.
